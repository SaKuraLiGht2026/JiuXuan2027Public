1.使用方法

“UART_Double_Buffer/Inc/drv_uart_double_buffer.h”有一个结构体和两个函数，具体如下:

首先是结构体：

typedef struct { UART_HandleTypeDef *UART_Handler; UART_Callback Callback_Function; uint8_t Rx_Buffer_A[UART_BUFFER_SIZE]; uint8_t Rx_Buffer_B[UART_BUFFER_SIZE]; uint8_t *Rx_Buffer_Active; uint8_t *Rx_Buffer_Already; // 接收时间戳 uint64_t Rx_Time_Stamp; }Drv_UART_Manage_Object;

然后是初始化函数，其定义如下：

DRV_UART_Manage_StatusTypedef UART_Init(Drv_UART_Manage_Object *UART_Manage_Object, UART_HandleTypeDef *huart, UART_Callback Callback_Function) { if (UART_Manage_Object != NULL) { UART_Manage_Object->UART_Handler = huart; UART_Manage_Object->Callback_Function = Callback_Function; UART_Manage_Object->Rx_Buffer_Active = UART_Manage_Object->Rx_Buffer_A; HAL_UARTEx_ReceiveToIdle_DMA(UART_Manage_Object->UART_Handler, UART_Manage_Object->Rx_Buffer_Active, UART_BUFFER_SIZE); return DRV_UART_OK; }else { return DRV_UART_ERR; } }

还有重初始化函数，其定义如下：

DRV_UART_Manage_StatusTypedef UART_Reinit(Drv_UART_Manage_Object *UART_Manage_Object, UART_HandleTypeDef *huart) { if (UART_Manage_Object != NULL) { UART_Manage_Object->UART_Handler = huart; UART_Manage_Object->Rx_Buffer_Active = UART_Manage_Object->Rx_Buffer_A; HAL_UARTEx_ReceiveToIdle_DMA(UART_Manage_Object->UART_Handler, UART_Manage_Object->Rx_Buffer_Active, UART_BUFFER_SIZE); return DRV_UART_OK; } else { return DRV_UART_ERR; } }

需要注意的是，头文件开头有一行代码如下：

/** * @brief UART通信接收回调函数数据类型 */ typedef void (*UART_Callback)(uint8_t *Buffer, uint16_t Length);

这个就如我的注释所示，后面使用的时候用来注册回调函数用的。

注意包含头文件这种事情应该不需要我讲了。

怎么使用呢？首先（以我达妙开发板的UART10为例，下文亦然），找一个地方写下：

Drv_UART_Manage_Object UART10_Manage_Object;

注意还要注册一个回调函数：

void HIPNUC_UART_Callback_Function(uint8_t *Buffer, uint16_t Length) { /* your callback function code */ }

然后初始化：

UART_Init(&UART10_Manage_Object, &huart10, HIPNUC_UART_Callback_Function);

完事后就去你自己的串口回调函数上写如下代码（这里以DMA空闲接收中断为例）：

UART10_Manage_Object.Rx_Buffer_Already = UART10_Manage_Object.Rx_Buffer_Active; if (UART10_Manage_Object.Rx_Buffer_Active == UART10_Manage_Object.Rx_Buffer_A) { UART10_Manage_Object.Rx_Buffer_Active = UART10_Manage_Object.Rx_Buffer_B; }else { UART10_Manage_Object.Rx_Buffer_Active = UART10_Manage_Object.Rx_Buffer_A; } HAL_UARTEx_ReceiveToIdle_DMA(&huart10, UART10_Manage_Object.Rx_Buffer_Active, UART_BUFFER_SIZE); // 上面这个根据你自己的串口接收方式看着来改 __HAL_DMA_DISABLE_IT(&hdma_usart10_rx, DMA_IT_HT); // Disable Half Transfer interrupt for DMA // 这玩意我在DMA空闲中断用的，就是关掉DMA接收过半中断 if (UART10_Manage_Object.Callback_Function != nullptr) { UART10_Manage_Object.Callback_Function(UART10_Manage_Object.Rx_Buffer_Already, Size); }

好了，现在基本上就可以用了。剩下的细枝末节问题可以通过Debug解决。

2.注意事项

有一个需要注意的点就是达妙开发板的DMA访问的内存区域有规定的，比如DTCM这个地方喵板的DMA就访问不了，所以保险起见可以在你定义的结构体变量前加上点东西，具体可以参考我之前写的《一些针对达妙开发板的DMA发送不了的解（歪）决（门）办（邪）法（道）》来改，强行把你的结构体变量地址改到DMA可以访问的地址。
